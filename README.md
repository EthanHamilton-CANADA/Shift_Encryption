# Shift_Encryption
PNG files are a lossless image format for which many other filetypes (e.g., JPEG, JPG, PDF) support conversion to/from.  Due to this popularity, PNG files can often store sensitive information- i.e., pictures of void cheques, passwords, restricted designs, etc.  This program thereby was designed to encrypt and/or decrypt such files and thereby provide an elevated level of security.

Imagine a singular completed face of a Rubik's Cube, and that such a face conveys the likeness of an image.  Should we then scramble the Rubik's Cube, we get a disordered face, and a disordered picture, where few, if any, individuals could ever tell that the specific Rubik's Cube had ever been solved, or that any wothwhile data had ever been present on the image.  However, if we had remembered each and every turn to scramble the Rubik's Cube, applying them in reverse would cause us to unscramble the face, and solve the puzzle.  It is this process that brings us to a similar thing which is done with the files used in this program.  We scramble all image files with a series of instructions that shift each individual column and row of pixel data by a pseudorandom number, and store those series of numbers as a decryption key, for which we can later apply to the encrypted image (in reverse) to restore our original unencrypted files.  It isn't an unbreakable form of encryption, and one still has to manually delete the original files present within the 'resources' folder and the OS trash can, and certainly store the decryption keys and encrypted files separately, but it works, and should prevent intrusion from moderately motivated prying eyes.

On Windows computers, simply download the raw 'Installer_Shift Encryption.jar' file, double-click it to run, and select a folder in which you would like to use as your workspace for this encryption program- then hit launch- note this will not shutdown the program should you want to select more than one file location.  Once complete, you will be faced with a new folder at the specified location labeled 'Shift Encryption' in which 4x folders labeled 'decrypted', 'dec_keys', 'encrypted', 'resources', and 2x .jar files labeled 'Encrypt.jar' and 'Decrypt.jar' will be present.  Then, simply put your PNG, JPEG, and/or JPG files into the 'resources' folder and double-click the 'Encrypt.jar' program to encrypt them- thereby populating the 'dec_keys' folder with .txt files corresponding to encrypted files now present within the 'encrypted' folder.  Now, if you're serious about your security, this is when you should delete the original image files present within the 'resources' folder and OS, and separate the decryption keys and encyrpted images onto separate drives.  However, if you would like to decrypt them, then re-introduce the decryption key .txt files back into the 'dec_keys' folder and the encrypted images back into the 'encrypted' folder.  Then, simply double click 'Decrypt.jar' and open the 'decrypted' folder to view your decrypted files.  DO NOT MESS WITH FILE NAMES, DO NOT MIX UP ENCRYPTION/DECRYPTION BATCHES/KEYS.  Note that all image files are converted to PNG upon encryption.
